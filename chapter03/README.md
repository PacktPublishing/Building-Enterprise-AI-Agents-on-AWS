# Chapter 3 - CrewAI environment and scaffold

This chapter prepares the development environment and inspects the CrewAI project structure. It does not require creating AWS application resources.

- `01_environment_setup/README.md`: recurring environment checks used by the chapter
- `02_crewai_scaffold/vacation_planner/`: the supplied CrewAI project structure used as the baseline for Chapter 4

The book uses the named AWS profile `agent-builder` and Region `us-east-1` for its readiness checks.
