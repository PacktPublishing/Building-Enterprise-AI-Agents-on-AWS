# Chapter 9 - AgentCore Identity with Amazon Cognito

This chapter uses a Cognito machine-to-machine application to obtain a scoped OAuth 2.0 access token for the AgentCore Gateway path.

- `01_cognito_m2m_setup/README.md`: configuration checklist
- `02_token_test/token_test.py`: sanitized token request and safe JWT claim inspection

Do not print or commit access tokens or client secrets.
